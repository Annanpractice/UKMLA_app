## Safe use in the UKMLA app

The image manifest can support condition tagging, duplicate detection, image-gap analysis and search terms. `redistributionAllowed` is deliberately false for every Spranki image. A public app should use separately licensed, public-domain, self-created or generated replacements.

The condition taxonomy can be compared with the app's condition IDs to identify missing aliases, subconditions and thin topic areas. No clinical claim should be imported without independent verification against current UK guidance.
